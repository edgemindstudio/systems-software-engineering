# Lab 01-02 — Pointer Mechanics

## Objective

Practice pointer arithmetic, indirection, pointer-to-pointer mutation, and array traversal without relying on undefined behavior.

## Engineering Focus

The implementation demonstrates:

- array decay versus explicit addresses;
- dereferencing and mutation;
- pointer arithmetic within one array object;
- pointer-to-pointer output parameters;
- safe in-place reversal;
- const-correct read-only traversal.

## Employer Signal

Pointer code is kept small, testable, and explicit about ownership and valid address ranges rather than using pointers as unexplained syntax.
