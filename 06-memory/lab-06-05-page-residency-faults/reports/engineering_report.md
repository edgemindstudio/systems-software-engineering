# Page Residency and Faults — Engineering Report

## Objective

Inspect anonymous-page residency and observe minor page faults generated by first-touch memory access.

## Runtime Observations

```text
resident_before=0
resident_after=64
minor_fault_delta=64
pages_touched=64
all_pages_resident_after_touch=yes
minor_faults_observed=yes
```

## Engineering Interpretation

Immediately after the anonymous mapping was created, none of the 64 pages were resident.

Touching one byte in each page caused all 64 pages to become resident.

The recorded minor-fault delta was exactly 64, matching the number of first-touched pages in this run.

This demonstrates demand paging: virtual address space can exist before physical pages are committed to the process.

## Result

PASS — residency changes and minor page faults were observed and correlated with page touching.
