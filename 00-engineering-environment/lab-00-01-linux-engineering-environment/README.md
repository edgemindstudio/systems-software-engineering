# Lab 00-01 — Linux Engineering Environment

## Objective

Establish and verify a Linux development environment suitable for practical systems software engineering.

## Skills Practiced

- Linux environment inspection
- compiler/toolchain verification
- debugger verification
- build-tool verification
- static-analysis verification
- tracing and profiling tool verification
- binary-tool verification
- environment documentation

## Tasks

1. Inspect the operating system and kernel.
2. Verify the C and C++ compilers.
3. Verify build systems.
4. Verify debugging tools.
5. Verify static-analysis tools.
6. Verify tracing and profiling tools.
7. Verify binary inspection tools.
8. Record the environment in a reproducible report.
9. Identify missing or incorrectly configured tools.

## Deliverables

- `scripts/check_toolchain.sh`
- `evidence/toolchain_check.txt`
- `reports/environment_report.md`

## Completion Criteria

This lab is complete when:

- the environment-check script executes successfully;
- installed tools and versions are recorded;
- missing tools are identified;
- the report explains whether the machine is ready for later systems labs.
